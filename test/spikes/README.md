# Language spikes

Small programs that confirm idioms of the compiler re-implementation against the stage0 compiler, before the new code
uses them widely (`media/specs/compiler-reimplementation.md`, section 7.3). The results are recorded there. The programs
stay here, so that the spikes can be repeated after a stage0 bump.

| File                          | Spike                                                                 |
|-------------------------------|-----------------------------------------------------------------------|
| `phantom-ids.spice`           | phantom-typed generic ids                                             |
| `phantom-ids-mismatch.spice`  | negative half: mixing two id types must not compile                   |
| `idvec-heap.spice`            | generic `IdVec<T>` holding structs with `heap` fields                 |
| `interface-defaults.spice`    | interface with default methods, implemented by a generic struct       |
| `tagged-union-loop.spice`     | cost of the tag check of a union with eight members                   |
| `mutual-imports/`             | one struct per file, mutual imports between the files                 |
| `dispatch.spice`              | `switch` vs. interface dispatch on 78 kinds (generated by `gen-dispatch.py`) |

```sh
export SPICE_STD_DIR=$PWD/std
S=build/stage0/spice

# Correctness (the `#[test]` functions)
for f in phantom-ids idvec-heap interface-defaults tagged-union-loop dispatch; do $S test test/spikes/$f.spice; done
$S test test/spikes/mutual-imports/main.spice
$S build test/spikes/phantom-ids-mismatch.spice        # must fail: 'declIndex(Id<Sym>)' could not be found

# Timings: release builds, which print the times of both variants. Run them a few times, the noise is high
$S build -O2 -o build/spike-union test/spikes/tagged-union-loop.spice && build/spike-union
$S build -O2 -o build/spike-dispatch test/spikes/dispatch.spice && build/spike-dispatch

# Regenerate the dispatch spike
python test/spikes/gen-dispatch.py > test/spikes/dispatch.spice
```
